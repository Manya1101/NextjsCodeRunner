How to record the screen (suggestions)
- Open the app: npm run dev and visit http://localhost:3000
- Start your OS recorder:
  - macOS: QuickTime Player > New Screen Recording
  - Windows 10/11: Win+G (Xbox Game Bar) or use OBS
  - Linux: use OBS or built-in recorder
- Demonstrate:
  1. Type or paste code with missing semicolons/braces.
  2. Click Auto-Fix and show the changes.
  3. Click Run and show console output/errors.
  4. Open Help, type a keyword (e.g., semicolons) and show the response.
- Save the recording as MP4 and optionally upload to GitHub or a cloud drive.
